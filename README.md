# 엄마 근무표

큰 글씨로 쉽게 쓰는 요양보호사 근무표 웹앱입니다.

- 주간/야간/휴무/비번 원터치 입력
- 사용자 정의 반복 근무 자동 채우기
- 날짜별 메모 및 메모 표시
- 월별 근무 합계
- 월간 근무표 PNG 이미지 저장/공유 메뉴
- JSON 백업 및 복원
- 로컬 브라우저 저장, 광고/로그인/근무 알림 없음
- 앱 전용 캐시만 관리하는 서비스 워커

## 배포
모든 파일을 GitHub 저장소 루트에 올리고 Settings > Pages에서 `main` / `/(root)`를 선택합니다.

## 홈 화면 추가
- Android/Chrome: 메뉴(⋮) > 홈 화면에 추가 또는 앱 설치
- iPhone/Safari: 공유 버튼 > 홈 화면에 추가

기록은 각 기기에 저장되므로 아이폰과 갤럭시 사이에 자동 동기화되지 않습니다. 기기 변경 전 백업 파일을 저장하세요.
